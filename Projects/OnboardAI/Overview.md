# OnboardAI — Feature Overview

**Feature:** AI-Powered Employee Onboarding
**Status:** MVP Complete
**Last Updated:** 2026-09-04

## What is OnboardAI?

OnboardAI is an AI-powered onboarding feature that:
- Answers new hire questions using RAG over policy documents
- Provides source citations with every answer
- Tracks inference costs
- Escalates unknown answers to HR

## Acceptance Criteria (from PRD)
- AC2.1: Answers grounded in uploaded policy docs
- AC2.2: Source citations with every answer
- AC2.3: Response time < 3 seconds
- AC2.4: Unknown answers trigger HR escalation
