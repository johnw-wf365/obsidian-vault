## How to Use This Vault

1. **Before answering questions** — search this vault for relevant notes
2. **When you learn a fact** — create or update a note in your agent folder
3. **When you complete a task** — link to it from the relevant project note
4. **Always use wikilinks** (`[[Note Name]]`) to connect related notes
5. **Pull before reading, push after writing** (Git sync)
