# Product Roadmap — Calculator Platform

Created as part of [[WOR-1707]].

## Summary
- 6-month roadmap defined (Sep 2026 – Feb 2027)
- Month 1: MVP launch (10 calculators, .com + .co.uk)
- Month 2: User accounts + premium
- Month 3: SEO content + growth
- Month 4: Canada + Australia expansion
- Month 5: Advanced calculators + API
- Month 6: B2B + affiliate integrations

## Key Decisions
- **Single hub site** with geo-routing (not separate brands) — SEO consolidation wins
- **6 categories** for IA — cognitive load research supports 5±2
- **3-tier freemium**: Anonymous (3/day) → Registered (10/mo) → Premium (£4.99/mo)
- **No credit card for trial** — reduces friction
- **10 MVP calculators** selected by search volume, CPC, and implementation ease
