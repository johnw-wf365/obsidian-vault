## Brand Identity

### Name Recommendation: Numera

5 name options evaluated:
1. **Numera** — Latin "numerus", premium, available (RECOMMENDED)
2. Calcify — modern verb form, energetic
3. Tally — friendly, British, but likely taken
4. Figure — double meaning, sophisticated
5. OmniCalc — descriptive, SEO-friendly

### Logo Direction

- Abstract "N" mark formed by overlapping calculation symbols
- Badge version for favicon/social
- No calculator/abacus iconography — too literal
- Navy + Teal color scheme

### Color Scheme

| Role | Color | Hex |
|------|-------|-----|
| Primary | Deep Navy | `#1B2A4A` |
| Secondary | Teal | `#0D9488` |
| Accent | Amber | `#F59E0B` |
| Background | Light Gray | `#F8FAFC` |
| Surface | White | `#FFFFFF` |

### Tagline

"Every calculator. One place."

### Positioning Statement

Numera is the free, fast calculator platform for people who need answers now — not accounts, not friction, not clutter. We serve US, UK, Canadian, and Australian audiences with tools they use daily, supported by respectful ads and an optional premium tier.

## AdSense Optimization

### Ad Placements

| Position | Format | RPM Impact |
|----------|--------|------------|
| Top leaderboard | 728×90 | Baseline |
| Inline content | In-feed responsive | +15-25% |
| Sidebar | 300×250 | +10-15% |
| Sticky bottom (mobile) | 320×50 | +20-30% |
| Result box | Contextual | +10-20% |

### A/B Tests Planned

1. Ad density (2 vs 3 per page)
2. Ad position above calculator
3. Ad position below result
4. Sidebar sticky vs static
5. Mobile format (sticky bottom vs inline)

### Compliance

- No clicking own ads
- No "click here" language
- Cookie consent banner (GDPR)
- Ad density below 30%
