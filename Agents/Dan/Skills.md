# Dan's Social Media Skills

Dan has 7 specialized skills for social media management. Each skill is loaded on demand to handle specific tasks.

## Skills Overview

| Skill | Purpose | Tools Used |
|-------|---------|------------|
| **social-graphics** | Generate images for social media | Leonardo AI, Ideogram, Bing Image Creator, Adobe Firefly |
| **social-video** | Create and edit video content | CapCut, Canva Video, Clipchamp, Opus Clip |
| **social-analytics** | Track metrics and generate reports | Meta Business Suite, LinkedIn Analytics, YouTube Studio, TikTok Analytics, GA4, Looker Studio |
| **social-monitoring** | Monitor mentions and trends | Google Trends, Twitter/X Search, Reddit, Feedly, Google Alerts |
| **social-posting** | Schedule and publish content | Meta Business Suite, LinkedIn, Twitter/X, TikTok, Buffer |
| **social-engagement** | Respond to community | Meta Business Suite Inbox, Twitter/X Notifications, LinkedIn Notifications, TikTok Inbox |
| **social-charts** | Generate charts and graphs | QuickChart API, Matplotlib, Chartli |

## Workflow

```
Monitoring → detects trend/mention
    ↓
Engagement → drafts response (if needed)
    ↓
Graphics/Video → creates visual content
    ↓
Charts → generates analytics visuals
    ↓
Posting → publishes to platforms
    ↓
Analytics → tracks performance
    ↓
Back to Monitoring (cycle repeats)
```

## Skill Location

All skills are stored at: `~/.hermes/skills/marketing/`
