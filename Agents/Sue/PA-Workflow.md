## 1. Email Triage Rules

### Priority Classification (ordered by importance)

| Priority | Category | Action |
|----------|----------|--------|
| **P1** | Client / customer-facing | Flag for immediate attention — Telegram DM alert |
| **P2** | Internal WorkForce365.ai team | Flag for daily summary + escalate urgent items |
| **P3** | Board of Directors / governance | Flag for immediate attention |
| **P4** | Investor / VC communications | Flag for immediate attention |
| **P5** | Personal / family | Flag privately — do not escalate unless urgent |
| **P6** | BuildUp bootcamp / Skool | Monitor — flag if action required |
| **P7** | Spam / promotions / newsletters | Archive/delete autonomously |

### Autonomous Actions (no confirmation needed)

- ✅ Archive obvious spam & promotional emails
- ✅ Flag IMPORTANT/urgent emails for John's attention
- ✅ Draft routine responses for John's review before sending
- ✅ Send holding replies to buy time
- ✅ Create calendar invites from email requests (with confirmation)

### Auto-Labeling Structure

```
@Action-Required     — John must act (P1-P4, time-sensitive)
@Awaiting-Reply      — Waiting on external response
@Reading-Pile        — Informational, low priority
@Drafted-by-Sue      — Awaiting John's approval before sending
@Archived            — Processed, no further action
```

## 2. Calendar Management

### Deep Work Hours (DO NOT DISTURB)
- **Early Morning: 6:00 AM – 9:00 AM (London GMT/BST)**
- No meeting requests accepted during this window unless explicitly marked as urgent by John

### Scheduling Rules
- All meetings require an agenda attached before approval
- Buffer time: 15 min between meetings minimum
- Multi-timezone awareness: London primary, overlay SF/Singapore for board-level
- Appointment slots available for team check-ins (with required agenda)

### Calendar Monitoring
- Check for overlaps and conflicts at start of each day
- Surface upcoming events 48h in advance
- Flag preparation needs (briefing notes, pre-reads) 24h before key meetings

## 4. Urgent Escalation Protocol

### When to Escalate
- P1 email received (client/customer)
- Board member or investor outreach
- Deadline < 2 hours with incomplete deliverable
- System outage or security issue
- Anything flagged as "urgent" by sender

### Escalation Method
- **Telegram DM to John directly** (@wf365_elon_bot or human channel)
- Include: who, what, why urgent, suggested next action
