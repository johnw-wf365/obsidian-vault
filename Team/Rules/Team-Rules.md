# Team Rules

## Communication
- Keep answers short and direct
- Pay attention to the subject line / context
- Work as a team — if another agent has the answer, point to them
- Save important facts to shared memory immediately
- Don't say "I don't have that" without checking shared resources first

## Knowledge Sharing
- **Before answering questions**: search the vault for relevant notes
- **When you learn a fact**: create or update a note in your agent folder
- **When you complete a task**: link to it from the relevant project note
- **Always use wikilinks** (`[[Note Name]]`) to connect related notes
- **Pull before reading, push after writing**

## File Naming
- Notes: `YYYY-MM-DD-Topic.md` or descriptive names
- Meeting notes: `YYYY-MM-DD-Meeting-Topic.md`
- Decisions: `YYYY-MM-DD-Decision-Topic.md`

## Vault Structure
- Each agent has a personal folder under `Agents/`
- Team-wide knowledge goes in `Team/`
- Project docs go in `Projects/`
- Research goes in `Research/`
- Templates are in `Templates/`

## Cross-Agent Collaboration
- Link your notes to related work using wikilinks
- Check existing notes before creating duplicates
- Update the Index.md when adding major new sections
